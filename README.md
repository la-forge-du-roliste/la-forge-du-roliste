# 🔥 La Forge du Rôliste

### Modules, automatisations et outils pour Foundry VTT

Bienvenue dans **La Forge du Rôliste** !

Je développe des modules pour **Foundry Virtual Tabletop**, principalement autour de **D&D 5e**, avec l'objectif d'améliorer l'automatisation, le confort de jeu et l'utilisation de Foundry autour d'une table physique.

---

## 🧩 Les modules de la Forge

### 🆓 Modules gratuits

| Module | Description |
|---|---|
| **Internal Activities** | Masque certaines activités D&D5e tout en les conservant disponibles pour les automatisations. |
| **Remote Action** | Permet de relayer certaines actions vers un autre client Foundry, notamment une table ou un écran central. |
| **PureCanva** | Interface pensée pour les écrans tactiles et les installations de table physique. |
| **Automatic Token Image** | Recherche et attribue automatiquement des images adaptées aux tokens depuis votre propre bibliothèque. |

---

### ✨ Étincelle

Disponibles pour les soutiens **Étincelle et supérieurs**.

| Module | Description |
|---|---|
| **Multi-Hit Spell Level Scaler** | Permet à certains sorts de gagner des frappes supplémentaires avec le niveau d'emplacement plutôt que des dégâts supplémentaires. |
| **Secondary AoE** | Ajoute des zones d'effet secondaires configurables autour des cibles. |

---

### 🔨 Forgeron

Disponibles pour les soutiens **Forgeron et supérieurs**.

| Module | Description |
|---|---|
| **Buff on Trigger** | Système avancé de buffs et d'effets déclenchés pour D&D5e. |
| **Persistent Zones** | Création et gestion de zones persistantes avec déclencheurs, déplacements et automatisations. |
| **TableDeck** | Intégration avancée de Stream Deck avec Foundry VTT pour joueurs et MJ. |
